Installation
============

To install Swarmy and its dependencies:

.. code-block:: bash

   git clone https://github.com/crismicheli/swarmy.git
   cd swarmy
   pip install -e .
   pip install -e .[dev,visualization,analysis]

Requirements:
- Python >= 3.7
- numpy
- (Optional) pygame, matplotlib, pandas, seaborn

For more, see the README or CONTRIBUTING.md.
